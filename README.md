# Zayd & Razan Challenge

Application Android éducative pour les enfants de 8 à 12 ans : apprentissage ludique du français et du néerlandais à travers les monuments de Paris.

## MVP

- Association de mots français–néerlandais
- Écouter et choisir la bonne réponse
- Quiz sur les monuments de Paris
- Progression locale, sans compte

Le développement du MVP se poursuit sur une branche dédiée.
